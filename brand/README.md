# plaqo brand kit

Social and repo assets. Each image has an `.svg` source (text already outlined, so it needs no fonts) next to its `.png` export.

| File | Size | Where it goes |
|---|---|---|
| `avatar-paper.png` | 1024×1024 | Profile picture on a light background: Instagram, LinkedIn page logo, GitHub org |
| `avatar-ink.png` | 1024×1024 | Profile picture on a dark background (the brand account default) |
| `x-header.png` | 3000×1000 (1500×500 @2x) | X / Twitter header. The copy is right-aligned because the avatar covers the bottom-left corner |
| `linkedin-cover.png` | 2256×382 (1128×191 @2x) | LinkedIn company page cover. Right-aligned for the same reason |
| `github-social-preview.png` | 1280×640 | GitHub repo → Settings → Social preview |

The avatars leave enough margin for circular crops (X, Instagram, GitHub).

**Colors.** Paper `#F4F1EB`, ink `#181714`, vermilion `#9D3326` (`#C6613F` on ink).
**Type.** Newsreader 560 for the wordmark, Newsreader italic for the tagline, Geist Mono for the domain.

The site's own icons and OG image live in `public/`.
